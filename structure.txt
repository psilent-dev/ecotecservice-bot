Структура интерфейса бота «Экотек Сервис» (Mini App First)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Концепция:
• Упор на Telegram Mini App (TMA): выбор услуг, расчёт стоимости и запись
  на дату происходят в веб-интерфейсе с Glassmorphism-дизайном.
• Нет барьера на входе: телефон не запрашивается принудительно на шаге /start.
  Клиент сразу видит витрину, цены и преимущества сервиса.
• Резервный сценарий в чате: экспресс-запись «Перезвоните мне» в 1–2 клика
  для тех, кто не хочет или не может открывать WebApp.

Навигация:
• Menu Button (системная кнопка слева от поля ввода): WebApp → https://ecotecservice.ru/tg
• Основные экраны: Inline-кнопки (кнопка WebApp + обычные callback-кнопки).
• Reply-клавиатура: ТОЛЬКО при выборе экспресс-записи в чате («📱 Отправить контакт»).

Команды:
  /start              приветствие, начисление бонуса, меню
  /start ref_XXXXXXXX реферальный deep-link (приглашение друга)
  /admin              админ-панель (только для администраторов)
  /cancel             сброс любого активного FSM → возврат в меню

2. КЛИЕНТСКИЕ СЦЕНАРИИ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2.1. Основной сценарий: Запись через Mini App (WebApp)
────────────────────────────────────
Кнопка: [ 🚀 Записаться онлайн (Калькулятор и цены) ]
Действие: открывает https://ecotecservice.ru/tg внутри Telegram на весь экран.

Функционал страницы WebApp:
• Имя и @username подтягиваются автоматически из Telegram WebApp SDK.
• Интерактивный калькулятор ТО и список услуг с ценами («от...»).
• Выбор даты, времени и ввод марки/модели авто.
• Ввод номера телефона (сохраняется в профиле навсегда).
• Тактильная отдача (Haptic Feedback) на кнопках.

Результат отправки из WebApp:
• WebApp закрывается.
• Клиенту в чат бота приходит красивый тикет:
  «✅ Заявка №XXX принята! Мастер свяжется с вами в течение 10 минут для подтверждения.»
• Администраторам уходит карточка новой заявки (см. раздел 4).


2.2. Резервный сценарий: Быстрая запись в чате (FSM QuickBooking)
────────────────────────────────────
Кнопка: [ ⚡ Быстрая запись в 1 клик ]
Назначение: для тех, кто за рулём или предпочитает обратный звонок.

Шаг 1. Если номер ещё не сохранён:
  «Оставьте ваш номер, и дежурный мастер перезвонит для подбора времени:»
  [ 📱 Отправить мой номер телефона ] (Reply-кнопка, request_contact)
  (или ввод текста вручную в формате +7XXXXXXXXXX)
  [ ❌ Отмена ] (Inline)

Шаг 2. Запрос марки или проблемы (необязательно):
  «Напишите марку авто или причину обращения (или нажмите пропустить):»
  [ ⏭ Пропустить ]  [ ❌ Отмена ]

Финал:
  «✅ Запрос на звонок принят! Мастер перезвонит вам в ближайшее время.»
  Админам падает карточка с пометкой «🔥 Срочный звонок».


2.3. Задать вопрос мастеру (FSM QuestionStates)
────────────────────────────────────
Кнопка: [ 💬 Задать вопрос ]

Шаг 1. «Напишите ваш вопрос. Можно прикрепить фото или аудио повреждения:»
  [ ❌ Отмена ]

Шаг 2. Подтверждение отправки:
  Предпросмотр вопроса клиента.
  [ ✅ Отправить мастеру ]  [ ❌ Отмена ]

Финал:
  «Вопрос передан в ремзону. Ответ мастера придёт прямо в этот чат.»


2.4. Мой профиль и бонусы
────────────────────────────────────
Кнопка: [ 🎁 Мои бонусы ]

Карточка сообщения:
• Имя клиента
• Номер телефона (или статус: «Не привязан»)
• Баланс бонусов (рубли)
• Количество визитов: N
• Реферальная ссылка: https://t.me/ecotec_service_bot?start=ref_XXXXXXXX
• Условия: «Пригласите друга — он получит 10% на первый визит, а вы — бесплатную диагностику!»

Inline-кнопки:
├─ [ 🚀 Записаться и списать бонусы ] (кнопка WebApp: /tg)
├─ [ 👥 Поделиться ссылкой с другом ] (switch_inline_query с текстом инвайта)
└─ [ 🏠 В главное меню ]


2.5. Контакты и маршрут
────────────────────────────────────
Кнопка: [ 📍 Контакты и маршрут ]

Карточка сообщения:
• Адрес автосервиса
• График работы: Ежедневно с 09:00 до 20:00
• Прямой телефон мастера-приёмщика

Inline-кнопки:
├─ [ 🗺 Построить маршрут (Яндекс Карты) ] (URL)
├─ [ 📞 Позвонить на сервис ]              (URL tel:+7XXXXXXXXXX)
└─ [ 🏠 В главное меню ]


2.6. Диалог по заявке (общение мастера и клиента)
────────────────────────────────────
Когда администратор отвечает на вопрос или заявку, клиенту приходит сообщение:
«👨‍🔧 Сообщение от мастера по вашей заявке №XXX:
[Текст ответа]»

Inline-кнопки под ответом:
├─ [ 💬 Ответить мастеру ] (ввод текста клиентом)
└─ [ 🔒 Вопрос решён ]      (закрытие диалога)


3. АДМИН-ПАНЕЛЬ (/admin)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Главное меню администратора:
«👑 Панель управления «Экотек Сервис»»
├─ [ 📥 Новые заявки (N) ]
├─ [ 💬 Открытые диалоги ]
├─ [ 👥 База клиентов ]
├─ [ 📢 Сделать рассылку ]
├─ [ ⚙️ Услуги и цены ]     (редактирование позиций для WebApp)
├─ [ 🎁 Промокоды и акции ]
├─ [ 📊 Статистика ]        (заявки за день / неделю / месяц)
└─ [ ↩️ В клиентское меню ]


3.1. Раздел заявок
────────────────────────────────────
Список карточек с пагинацией (по 5 штук):
[ Заявка #142 · Mini App · Hyundai Solaris · Новая ]
[ Заявка #141 · Быстрая · Kia Rio · В работе ]
[⬅️ Назад] [Стр 1/3] [Вперед ➡️]

При клике на заявку:
• Детальная информация (источник, контакты, авто, выбранные услуги, дата).
• Кнопки управления:
  ├─ [ ✅ Подтвердить время ] (отправляет клиенту пуш «Запись подтверждена на ЧЧ:ММ»)
  ├─ [ 💬 Написать клиенту ]  (FSM ввод текста)
  ├─ [ 📞 Позвонить ]         (ссылка tel:)
  └─ [ 🔒 Закрыть заявку ]


3.2. База клиентов
────────────────────────────────────
• Список клиентов (по 10 на страницу).
• Поиск по имени, номеру телефона или госномеру (FSM).
• Карточка клиента:
  ├─ [ ✍️ Личное сообщение ]
  ├─ [ 🎁 Начислить бонусы ]
  └─ [ 🚫 Заблокировать / Разблокировать ]


3.3. Управление услугами и ценами (Синхронизация с WebApp)
────────────────────────────────────
Категории (ТО, Подвеска, Диагностика, Электрика, Тормозная система, ДВС, Шиномонтаж).
В каждой услуге:
• Название
• Цена «от»
• Активность (Показывать / Скрыть в WebApp)
• [ ➕ Добавить услугу ] / [ 🗑 Удалить ]


3.4. Массовая рассылка (FSM Broadcast)
────────────────────────────────────
Шаг 1. Отправка текста, фото или поста акции.
Шаг 2. Предпросмотр с отображением количества получателей.
Шаг 3. [ 🚀 Запустить рассылку ]  [ ❌ Отмена ]
